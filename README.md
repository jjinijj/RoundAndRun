# RoundAndRun

Unity 기반 엔들리스 러너 게임. 자동으로 전진하는 플레이어가 장애물을 점프/슬라이드로 피하고 아이템을 수집합니다.

> **현재 개발 중인 프로토타입입니다.**

**플레이 링크**: https://round-and-run.vercel.app/

## 주요 기능

- **테마 시스템** — `BGThemeData` ScriptableObject로 배경 타일, 장식물, 장애물, 아이템, BGM을 테마 단위로 관리
- **Map Editor** — Unity 에디터 툴(`Game > Map Editor`)로 레벨 JSON 파일을 GUI로 편집/저장/불러오기
- **아이템 다양화** — `ScoreItem`(점수 획득), `HealItem`(체력 회복) 구현
- **UI** — 체력바(fillAmount), 데미지 비네트 이펙트, 일시정지 패널
- **사운드** — BGM / SFX(점프, 슬라이드, 피격, 아이템 획득) 분리 재생

## 개발 예정

- **난이도 상승** — 오래 달릴수록 맵 이동 속도 증가
- **맵 패턴 다양화** — 고정 패턴 반복에서 다양한 패턴으로 개선

## 조작법

| 액션 | 키보드 | 모바일 |
|------|--------|--------|
| 점프 | `Space` | Jump 버튼 |
| 슬라이드 | `↓` | Slide 버튼 |
| 게임 시작 | `S` | - |
| 일시정지 / 재개 | - | Pause 버튼 |
